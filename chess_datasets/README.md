# Grandmaster 2400 ELO Chess Training Datasets

## Overview
This repository collects and organizes self-play game datasets generated by the Grandmaster 2400 ELO Android Chess Trainer. Each dataset captures full move trajectories, clock allocations, positional evaluations, and match outcomes generated across 4 to 20 concurrent AI vs AI simulation workers.

## Directory Layout
```
chess_datasets/
├── README.md               # Dataset documentation, schema, and usage guide
├── dataset_index.json      # Master catalog of exported simulation sessions
├── sessions/               # Individual JSON session datasets
│   └── session_*.json      # Exported session files
└── scripts/                # Verification and sync tooling (M3)
    ├── validate_dataset.js
    └── sync_from_device.ps1
```

## JSON Schema Specification (Draft 2020-12)

Each exported JSON session file conforms to the following structure:

### Session Object
- `sessionId` (`string`): Unique session identifier (`session_YYYYMMDD_HHMMSS_<uuid>`).
- `version` (`string`): Schema version (currently `"1.0.0"`).
- `generator` (`string`): `"Grandmaster 2400 ELO Android Chess Trainer"`.
- `device` (`object`):
  - `model` (`string`): Device model.
  - `manufacturer` (`string`): Device manufacturer.
  - `osRelease` (`string`): Android OS version.
  - `sdkInt` (`integer`): Android SDK level.
- `timestamp` (`string`): ISO-8601 UTC timestamp of export.
- `concurrency` (`integer`): Number of simultaneous AI simulation threads (4 to 20).
- `totalGames` (`integer`): Total number of games completed in the session.
- `summary` (`object`):
  - `whiteWins` (`integer`): Number of games won by White.
  - `blackWins` (`integer`): Number of games won by Black.
  - `draws` (`integer`): Number of draws.
  - `whiteWinPct` (`number`): White win percentage (0.00 to 100.00).
  - `blackWinPct` (`number`): Black win percentage (0.00 to 100.00).
  - `drawPct` (`number`): Draw percentage (0.00 to 100.00).
  - `avgDurationMs` (`number`): Mean game duration in milliseconds.
  - `avgMoveCount` (`number`): Mean full-move count per game.
  - `avgMoveTimeMs` (`number`): Mean computation time per half-move in milliseconds.
- `games` (`array` of Game Objects): Full array of recorded games.

### Game Object
- `gameId` (`string`): Identifier for the game simulation instance.
- `index` (`integer`): 1-based index within the session.
- `whiteElo` (`integer`): 2400.
- `blackElo` (`integer`): 2400.
- `startTime` (`string`): ISO-8601 UTC timestamp of game start.
- `endTime` (`string`): ISO-8601 UTC timestamp of game completion.
- `durationMs` (`integer`): Elapsed game time in milliseconds.
- `outcome` (`string`): `"1-0"`, `"0-1"`, or `"1/2-1/2"`.
- `terminationReason` (`string`): One of `"checkmate"`, `"stalemate"`, `"insufficient_material"`, `"fifty_move_rule"`, `"threefold_repetition"`, or `"resignation"`.
- `totalPlies` (`integer`): Total half-moves played.
- `totalMoves` (`integer`): Total full moves played (`ceil(totalPlies / 2)`).
- `avgMoveTimeMs` (`number`): Average move computation time for this game.
- `moves` (`array` of Move Objects): Ordered sequence of plies.

### Move Object
- `ply` (`integer`): 1-based half-move index.
- `san` (`string`): Standard Algebraic Notation (e.g. `"e4"`, `"Nf3"`, `"O-O"`, `"Qxf7#"`).
- `from` (`string`): Source square in coordinate notation (e.g. `"e2"`).
- `to` (`string`): Destination square in coordinate notation (e.g. `"e4"`).
- `promotion` (`string|null`): Promotion piece (`"q"`, `"r"`, `"b"`, `"n"`) or null.
- `fen` (`string`): FEN string representing board state after the move.
- `turn` (`string`): `"w"` or `"b"`.
- `moveTimeMs` (`integer`): Calculation latency in milliseconds for this ply.
- `isCheck` (`boolean`): True if opponent king is in check after the move.
- `timestamp` (`string`): ISO-8601 timestamp when move was executed.

## Device Storage Paths & Sync Procedures

### Android Storage Locations
1. **Primary (Android 10+ MediaStore)**:
   - External path: `/storage/emulated/0/Download/ChessTrainer/<filename>.json`
2. **Fallback (App External Documents)**:
   - External path: `/storage/emulated/0/Android/data/com.voxelrealms.chesstrainer/files/Documents/<filename>.json`

### Pulling Datasets via ADB
```bash
# Pull all exported datasets from MediaStore downloads:
adb pull /sdcard/Download/ChessTrainer/ ./chess_datasets/sessions/

# Or pull from app external documents:
adb pull /sdcard/Android/data/com.voxelrealms.chesstrainer/files/Documents/ ./chess_datasets/sessions/
```
